CRUMBS
======

Open index.html in your browser to use the website.
Keep the assets folder beside index.html so the logo displays correctly.

This is a standalone concept demo. Instagram, LinkedIn and YouTube URL fields
are presentation inputs. Links are not fetched or analysed. The trail uses
Jane Doe's fictional case study. No installation or API key is needed.

An internet connection is optional; the page uses system font fallbacks when
Google Fonts is unavailable.

To host the website, upload index.html and the assets folder to a static host.

Live website: https://crumbs-privacy-trail.orangejay3.chatgpt.site
